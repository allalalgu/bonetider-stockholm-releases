# Bönetider – releases

Den här sidan innehåller bara installationsfiler (APK) för appen **Bönetider**. Appen visar bönetider för svenska städer från Islamiska Förbundet i Sverige.

## Installera

1. Öppna [senaste versionen](https://github.com/allalalgu/bonetider-stockholm-releases/releases/latest) på telefonen.
2. Ladda ner filen `BonetiderStockholm-x.y.z.apk` och öppna den.
3. Tillåt installation från webbläsaren eller filhanteraren om Android frågar.

Efter version 1.3.0 letar appen själv efter nya versioner en gång om dagen. Du får en avisering och ett kort i appen. Tryck på **Uppdatera** så installeras den nya versionen.

Alla versioner är signerade med samma nyckel. Android vägrar därför installera en uppdatering som inte kommer från samma utvecklare.
